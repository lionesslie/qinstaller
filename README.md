# QInstaller

Pacman ve Yay için basit bir terminal menüsü.

## Özellikler

- Paket Kurma
- Paket Silme
- Sistemi Güncelleme
- Pacman veya Yay seçimi

## Derleme

```bash
cargo build
```

## Kullanım

```bash
cargo run yada ./qinstaller
```

## Gereksinimler

- Rust
- Archlinux
