# QInstaller

Pacman ve Yay için basit bir terminal menüsü.

## Özellikler

- Paket Kurma
- Paket Silme
- Paket Arama
- Sistemi Güncelleme
- Pacman veya Yay seçimi

## Derleme

```bash
cargo build
```

## Kullanım

```bash
cargo run yada ./qinstaller
```

## Gereksinimler

- Rust
- Arch tabanlı bir dağıtım (pacman) ve/veya yay kurulu olmalı
